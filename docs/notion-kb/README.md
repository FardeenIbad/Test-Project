# ServQuik Notion Knowledge Base

Please add your Notion database exports to this folder.

## Required Files

Add the following Notion pages/databases as markdown (.md) or text (.txt) files:

1. **company-overview.md** - Company Overview / ServQuik Overview
2. **strategic-plan.md** - Strategic Plan
3. **products-solutions.md** - Products & Solutions database
4. **offer-library.md** - Offer Library / Power Offers database
5. **pricing-offers.md** - Pricing & Offers
6. **sops-playbooks.md** - SOPs & Playbooks
7. **case-studies.md** - Any case studies (Buchanan Insurance, Germania, etc.)

## How to Export from Notion

1. In Notion, go to each page
2. Click the "..." menu in the top right
3. Select "Export"
4. Choose "Markdown & CSV" format
5. Download and upload the files here

## File Naming

You can name the files however you like - I'll read all files in this folder. The names above are just suggestions.
